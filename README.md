# Portfolio — Louis Brookstein

Three projects, each one built for a named person with a specific problem.
The source repositories are private; these are the case studies.

---

### [Concept generator for Forming Reality](case-studies/forming-reality.md)

A brief → 3D spec → photoreal render → client deck pipeline for a shopfittings
manufacturer, so their business development lead could produce concepts himself
instead of queueing for a designer. **In production.**

<img src="images/forming-reality/03-in-store.jpg" width="640" alt="A retail display unit generated by the tool, shown in a shoe shop">

`TypeScript · Three.js · Claude · Gemini · Docker · Caddy`
119 commits to first deploy · ~10,800 lines · 16 real units built

---

### [Prova](case-studies/prova.md)

Version control and QA review for lab-automation scripts — an interactive demo
built to open a design partnership with Waters Corp's R&D reagents team.

<img src="images/prova/review-detail.jpg" width="640" alt="Prova protocol review screen">

`React · TypeScript · Vite · Tailwind`
5 modules · ~9,500 lines · deployed for unattended walkthrough

---

### [gxp-agent-core](case-studies/gxp-agent-core.md)

A regulation-driven context framework that makes a coding agent produce
inspection-ready pharmaceutical software by default — and assess existing
systems against the same criteria.

`Claude Code · Python · YAML`
8 regulations · 9 implementation patterns · machine-checked for consistency
